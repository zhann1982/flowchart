
# Flowi — редактор блок-схем в одном файле

**Flowi** — небольшое приложение для создания блок-схем прямо в браузере. Всё работает в одном HTML-файле: без установки, без сборки, без сервера и без зависимостей. Открыл файл — и рисуешь.

- Перетаскиваемые блоки и связи между ними
- Надписи в блоках и подписи на связях
- Яркий интерфейс, светлая и тёмная тема
- Интерфейс на русском и английском
- Локальное сохранение схем, история действий, комментарии
- Готовые шаблоны
- Экспорт схемы в SVG

## Быстрый старт

1. Скачай файл `index.html` (или `flowchart.html`).
2. Открой его двойным щелчком в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. При первом запуске загружается схема-заготовка. Меняй её или нажми **Новая**, чтобы начать с пустого холста.
4. Перетащи блоки из левой панели на холст, соедини их, подпиши.
5. Нажми **Сохранить** (или `Ctrl+S`). Схема появится в списке «Мои схемы».

Интернет нужен только для загрузки шрифтов с Google Fonts. Без него приложение работает так же, но с системными шрифтами.

## Обзор интерфейса

| Область | Что там |
|---|---|
| **Верхняя панель** | Название схемы, кнопки «Новая», «Шаблоны», «Мои схемы», отмена и повтор, «Сохранить», «Экспорт SVG», «По размеру», «Сетка», переключатели языка и темы |
| **Левая панель** | Палитра блоков: процесс, начало/конец, условие, данные, соединитель |
| **Холст** | Рабочая область с точечной сеткой |
| **Правая панель** | Настройки выбранного блока или связи. Если ничего не выбрано, там подсказка |
| **Нижняя панель** | Комментарии к текущей схеме. Панель можно свернуть кнопкой ▾ |

На узких экранах (телефон, планшет) панели выстраиваются друг под другом.

## Работа с блоками

### Виды блоков

| Блок | Для чего |
|---|---|
| **Процесс** (прямоугольник) | Обычное действие или шаг |
| **Начало/конец** (капсула) | Точка входа и завершения алгоритма |
| **Условие** (ромб) | Ветвление «да / нет» |
| **Данные** (параллелограмм) | Ввод и вывод данных |
| **Соединитель** (круг) | Точка слияния или переход на другую часть схемы |

### Добавление

- **Перетащи** блок из левой панели в нужное место холста.
- Или **нажми** на блок в палитре: он появится в центре видимой области.

### Перемещение

Захвати блок мышью и перетащи. Позиция привязывается к сетке с шагом 10 пикселей, поэтому блоки выравниваются аккуратно.

### Надпись

- **Двойной клик** по блоку открывает редактирование прямо на холсте.
- `Enter` сохраняет текст, `Shift+Enter` переносит строку, `Esc` отменяет изменение.
- Текст можно править и в поле «Надпись» в правой панели.

### Настройки выбранного блока

Выбери блок, и справа появятся его настройки:

| Настройка | Возможности |
|---|---|
| **Надпись** | Многострочный текст |
| **Форма** | Можно сменить форму, не удаляя блок |
| **Цвет** | 7 готовых цветов и выбор любого своего цвета. Цвет текста (тёмный или белый) подбирается автоматически для читаемости |
| **Размер текста** | От 10 до 32 px |
| **Ширина** | От 70 до 340 px |
| **Высота** | От 40 до 240 px |
| **Дублировать** | Создаёт копию со смещением |
| **Удалить** | Удаляет блок вместе со всеми его связями |

## Работа со связями

### Создание

1. Кликни по блоку, чтобы выбрать его. На краях появятся четыре розовые точки.
2. Зажми одну из точек и потяни на другой блок.
3. Отпусти кнопку мыши. Связь с стрелкой создана и сразу выбрана.

Стороны блоков для соединения подбираются автоматически, в зависимости от взаимного расположения блоков. Линия при этом остаётся плавной и следует за блоками при их перемещении.

### Настройки выбранной связи

| Настройка | Что делает |
|---|---|
| **Подпись связи** | Текст на линии, например «Да» или «Нет» |
| **Пунктирная линия** | Переключает сплошную и пунктирную линию |
| **Развернуть** | Меняет направление стрелки |
| **Удалить** | Удаляет связь |

Подпись можно также изменить **двойным кликом** по самой линии.

## Холст: масштаб, сдвиг, сетка

- **Масштаб:** колесо мыши (от 20% до 250%), масштабирование идёт относительно курсора.
- **Сдвиг:** зажми пустое место на холсте и перетащи.
- **По размеру:** кнопка подгоняет масштаб и положение так, чтобы вся схема поместилась на экране.
- **Сетка:** кнопка включает и выключает точечную сетку. Привязка блоков к шагу 10 px работает независимо от отображения сетки.

## Сохранение и «Мои схемы»

- **Сохранить** (`Ctrl+S`) записывает текущую схему в память браузера. Если название пустое, используется «Без названия».
- Повторное сохранение обновляет существующую схему, а не создаёт новую.
- Кнопка **Мои схемы** открывает список сохранённых схем. Для каждой видно название, дату последнего изменения, число блоков и число комментариев.
- В списке можно **открыть** схему для редактирования или **удалить** её.
- Чтобы отредактировать сохранённую схему, открой её, измени и снова нажми «Сохранить».
- Если в текущей схеме есть несохранённые изменения, перед открытием другой схемы, загрузкой шаблона или созданием новой приложение спросит подтверждение.

## История

Во вкладке **История** окна «Мои схемы» ведётся журнал действий: создание схемы, сохранение, добавление комментария, удаление, использование шаблона. У каждой записи есть время и название схемы. Хранятся последние 60 записей.

Отдельно работает **отмена и повтор** правок на холсте (кнопки ↶ и ↷, до 80 шагов). Эта история существует только пока страница открыта.

## Комментарии

Панель комментариев находится внизу и относится к текущей схеме.

- Напиши текст в поле (до 300 символов) и нажми **Добавить** или `Enter`.
- Новые комментарии показываются сверху, у каждого есть дата и время.
- Если комментариев больше **5**, появляется **пагинация**: кнопки ‹ и ›, а также номера страниц. На странице показывается по 5 комментариев.
- Комментарий удаляется кнопкой ✕ рядом с ним.
- Если схема ещё не сохранена, при добавлении первого комментария она сохраняется автоматически.
- Панель можно свернуть кнопкой ▾ в её заголовке, чтобы освободить место для холста.

## Шаблоны

Кнопка **Шаблоны** открывает набор заготовок. Шаблон становится основой новой схемы, а сохранённые схемы при этом не затрагиваются.

| Шаблон | Что в нём |
|---|---|
| **Заготовка** | Начало → процесс → условие → конец |
| **Вход в систему** | Ввод данных, проверка логина и пароля, ветки «Да» и «Нет», показ ошибки |
| **Разбор бага** | Проверка воспроизводимости и критичности, ветки: чинить сейчас, в бэклог, запросить детали |
| **Обработка заказа** | Проверка наличия на складе, оплата, отправка, уведомление об отсутствии товара |

Тексты в шаблонах подставляются на том языке, который выбран в интерфейсе в момент загрузки шаблона. После загрузки в схеме можно менять всё: тексты, цвета, размеры, связи.

## Экспорт

Кнопка **Экспорт SVG** скачивает схему как векторный файл `.svg` с названием схемы в имени файла.

- Файл содержит только сами блоки и связи, без сетки и без выделения.
- Фон соответствует текущей теме (светлый или тёмный).
- SVG открывается в браузере, редакторах вроде Inkscape и Figma, вставляется в документы и презентации.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+S` (`⌘S`) | Сохранить схему |
| `Ctrl+Z` (`⌘Z`) | Отменить |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Повторить |
| `Delete` / `Backspace` | Удалить выбранный блок или связь |
| `Esc` | Снять выделение |
| Двойной клик | Редактировать надпись блока или связи |
| Колесо мыши | Масштаб |

Клавиши отмены и удаления не срабатывают, пока курсор стоит в текстовом поле, чтобы не мешать вводу.

## Тема и язык

- Кнопка **☾ / ☀** переключает тёмную и светлую тему.
- Кнопка **RU / EN** переключает язык интерфейса.
- Выбор запоминается и применяется при следующем запуске. Если выбор ещё не делался, язык определяется по настройкам браузера.

Названия блоков и подписи, которые ты ввёл сам, при смене языка не переводятся: они остаются такими, какими ты их написал.

## Где хранятся данные

Все данные лежат в **localStorage** твоего браузера и никуда не отправляются.

| Ключ | Что хранит |
|---|---|
| `fc_charts` | Сохранённые схемы вместе с комментариями |
| `fc_log` | Журнал действий (история) |
| `fc_pref` | Язык, тема, состояние сетки |

Что важно знать:

- Данные привязаны к **браузеру и адресу страницы**. В другом браузере, на другом устройстве или при открытии файла по другому пути схем не будет видно.
- Очистка данных сайта или истории в браузере удалит и схемы. Для важных схем сделай экспорт в SVG.
- В режиме инкогнито данные исчезают после закрытия окна.

## Публикация на GitHub Pages

Чтобы приложение открывалось по ссылке:

1. Назови файл `index.html`.
2. Загрузи его в репозиторий (ветка `main`).
3. Открой **Settings → Pages**.
4. В разделе **Source** выбери ветку `main` и папку `/ (root)`, затем сохрани.
5. Через минуту-две приложение будет доступно по адресу вида `https://<имя-пользователя>.github.io/<репозиторий>/`.

Учти, что схемы каждого посетителя хранятся только в его собственном браузере.

## Структура кода

Весь код находится в одном файле и разбит на блоки с комментариями:

| Часть | Назначение |
|---|---|
| CSS | Цветовые переменные для двух тем, адаптивная вёрстка |
| Словарь `L` | Тексты интерфейса на русском и английском |
| Геометрия (`anc`, `ep`) | Расчёт точек соединения и кривых для связей |
| Разметка (`nd`, `eh`, `draw`) | Построение SVG-блоков и связей |
| События холста | Перетаскивание, соединение, масштаб, сдвиг |
| Инспектор (`insp`) | Правая панель настроек |
| Хранилище (`save`, `load`, `lg`) | Работа с localStorage |
| Шаблоны (`TP`) | Данные шаблонов в компактном виде |
| Комментарии (`cmr`, `addC`) | Список с пагинацией |
| Экспорт (`exp`) | Сборка автономного SVG |

Схема хранится в простой структуре: массив блоков `nodes` (`id`, форма, координаты, размеры, текст, цвет, размер шрифта) и массив связей `edges` (`id`, откуда, куда, подпись, признак пунктира).

**Как добавить свой шаблон.** В массив `TP` добавь объект: название на английском и русском, блоки в виде `[id, форма, x, y, текст EN, текст RU, цвет]` и связи в виде `[из, в, подпись EN, подпись RU]`. Формы: `rect`, `pill`, `dia`, `data`, `circ`.

## Ограничения

- Экспорт только в SVG (нет PNG и PDF), импорта из файла тоже нет.
- Между двумя блоками в одном направлении можно создать только одну связь. Связь блока с самим собой не поддерживается.
- Стороны, к которым крепятся связи, выбираются автоматически, вручную их менять нельзя.
- Отмена и повтор действуют только в рамках открытой страницы.
- Данные хранятся локально: синхронизации между устройствами нет.
- Если хранилище браузера переполнено, приложение покажет сообщение об ошибке сохранения.

## English summary

**Flowi** is a single-file flowchart editor (HTML + CSS + JS, no dependencies). Open the file in a browser and start drawing.

- **Blocks:** process, start/end, decision, data, connector. Drag them from the left palette or click to add. Double-click to edit text. Change shape, color, font size, width and height in the right panel.
- **Links:** select a block, drag from a pink dot on its edge onto another block. Add a label, make the line dashed, reverse it or delete it.
- **Canvas:** wheel to zoom, drag the background to pan, "Fit view" and a grid toggle.
- **Saving:** charts are stored in your browser's localStorage. Open "My charts" to see saved charts, edit or delete them, and the History tab with an activity log.
- **Comments:** shown at the bottom for the current chart, 5 per page, with pagination when there are more than 5.
- **Templates:** blank starter, login flow, bug triage, order processing.
- **Export:** SVG.
- **Interface:** light/dark theme, Russian/English, remembered between visits.
- **Shortcuts:** `Ctrl+S` save, `Ctrl+Z` / `Ctrl+Y` undo/redo, `Delete` remove, `Esc` deselect.

Data never leaves your browser. To publish the app, rename the file to `index.html` and enable GitHub Pages in the repository settings.
